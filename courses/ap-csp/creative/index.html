Big Idea 1: Creative Development

Open in StudyFox Free, no ads. Practice, track progress and quiz yourself in the app.

AP Computer Science Principles · Lesson 2 of 6 · 5 min read

  • Collaboration brings diverse perspectives and helps avoid bias. Pair programming is one approach.
  • Development process: investigate, design, prototype, test, and refine. It is often iterative.
  • Program documentation and comments help others (and future you) understand the code.
  • Errors: syntax errors (break the language rules), runtime errors (crash while running), logic errors (wrong output), and overflow errors (a number too big for its storage).
  • Testing uses normal, boundary, and unusual inputs.

Check your understanding

A program runs without crashing but calculates the wrong average. What kind of error is this?

  1. Syntax error
  2. Runtime error
  3. Logic error
  4. Overflow error

Answer: C. The program runs, but its instructions produce incorrect results, so it is a logic error.
