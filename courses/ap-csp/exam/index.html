The exam and the Create task

Open in StudyFox Free, no ads. Practice, track progress and quiz yourself in the app.

AP Computer Science Principles · Lesson 1 of 6 · 6 min read

  • Create performance task (30%): during the course you build a program, record a short video of it running, and make a Personalized Project Reference with code segments. On exam day you answer written questions about your own code.
  • End-of-course exam (70%): 70 multiple-choice questions in 2 hours, using the AP pseudocode reference sheet.

What your Create program needs

  • Input, output, a list (or other collection) that manages complexity, and a procedure with a parameter that includes sequencing, selection, and iteration, which you call in the program.
Tip Use a list in a way that truly matters. If your program would work the same with a few separate variables, explain why the list makes it easier to extend or maintain.
