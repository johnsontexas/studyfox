Big Idea 2: Data

Open in StudyFox Free, no ads. Practice, track progress and quiz yourself in the app.

AP Computer Science Principles · Lesson 3 of 6 · 7 min read

  • Binary: computers store everything as bits (0 or 1). With n bits you can represent $2^n$ values.
  • Converting: binary 1011 = 8 + 0 + 2 + 1 = 11 in decimal.
  • Compression: lossless keeps all data and can be fully restored (ZIP, PNG); lossy discards some data for smaller files (JPEG, MP3).
  • Metadata is data about data, like a photo's date and location.
  • Extracting information: cleaning data, filtering, and finding patterns. Correlation does not imply causation, and bias in data collection leads to biased results.
Bits

How many bits are needed to give each of 200 students a unique ID? $2^7 = 128$ is too few, and $2^8 = 256$ is enough, so 8 bits.
