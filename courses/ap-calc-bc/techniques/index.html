Integration techniques (BC)

Open in StudyFox Free, no ads. Practice, track progress and quiz yourself in the app.

AP Calculus: Exam Guide and BC Topics · Lesson 2 of 5 · 9 min read

  • Integration by parts: $\int u\,dv = uv - \int v\,du$. Pick $u$ using LIATE (logs, inverse trig, algebraic, trig, exponential).
  • Partial fractions (nonrepeating linear factors): $\frac{1}{(x - 1)(x + 2)} = \frac{A}{x - 1} + \frac{B}{x + 2}$.
  • Improper integrals: replace the infinite bound with a limit. $\int_1^\infty \frac{1}{x^p}dx$ converges only if $p > 1$.
  • Euler's method approximates solutions to differential equations: $y_{new} = y + \frac{dy}{dx}\Delta x$.
  • Logistic growth: $\frac{dP}{dt} = kP(1 - \frac{P}{L})$. Growth is fastest at $P = \frac{L}{2}$.
Example

$\int xe^x\,dx$: let $u = x$, $dv = e^x dx$. Then $= xe^x - \int e^x dx = xe^x - e^x + C$.
