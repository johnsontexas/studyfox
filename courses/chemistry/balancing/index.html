Balancing chemical equations

Open in StudyFox Free, no ads. Practice, track progress and quiz yourself in the app.

Chemistry Essentials · Lesson 3 of 5 · 6 min read

Atoms are never created or destroyed, so each element must have the same number of atoms on both sides. Change only the coefficients (numbers in front), never the subscripts.
Example

CH4 + O2 → CO2 + H2O

  1. Carbon: 1 on each side. Good.
  2. Hydrogen: 4 on the left, so put a 2 in front of H2O.
  3. Oxygen: now 2 + 2 = 4 on the right, so put a 2 in front of O2.

Balanced: CH4 + 2O2 → CO2 + 2H2O

Tip Balance elements that appear in only one compound on each side first, and leave H and O (or any lone element) for last.

Check your understanding

Balance: __H2 + __O2 → __H2O

  1. 1, 1, 1
  2. 2, 1, 2
  3. 1, 2, 2
  4. 2, 2, 2
Show answer

Answer: B. 2H2 + O2 → 2H2O has 4 H and 2 O on each side.
