The exam and how to write FRQ code

Open in StudyFox Free, no ads. Practice, track progress and quiz yourself in the app.

AP Computer Science A · Lesson 1 of 6 · 5 min read

The exam is 3 hours: a multiple-choice section (90 min) and four free-response questions (90 min) where you write Java methods and classes. A Java Quick Reference sheet lists the library methods you can use.

  • FRQs are graded on whether the logic is correct. Small syntax slips (a missing semicolon) usually aren't penalized; wrong logic is.
  • Use the method names, parameters, and return types exactly as given in the question.
  • If part (b) depends on part (a), you may call your part (a) method even if you didn't finish it.
Tip Trace code by hand with a table of variable values for each loop pass. That is how you'll solve most multiple-choice questions.

Check your understanding

On an FRQ, you can't solve part (a). Can you still call that method in part (b)?

  1. No, it will be marked wrong
  2. Yes, and it's assumed to work as specified
  3. Only if you rewrite it
  4. Only in the multiple-choice section
Show answer

Answer: B. Graders assume earlier methods work as described, so calling them in later parts can still earn full credit.
