Selection and iteration

Open in StudyFox Free, no ads. Practice, track progress and quiz yourself in the app.

AP Computer Science A · Lesson 3 of 6 · 9 min read

  • Boolean logic: && (and), || (or), ! (not). Java uses short-circuit evaluation: in a && b, if a is false, b isn't checked.
  • De Morgan's laws: !(a && b) equals !a || !b; !(a || b) equals !a && !b.
  • Loops: while runs while a condition is true; for is best for counting. Watch for off-by-one errors.
  • Common algorithms: sum, average, count matches, find min or max, and check if any or all elements meet a condition.
// Count the vowels in a word
int count = 0;
for (int i = 0; i < word.length(); i++) {
    if ("aeiou".indexOf(word.substring(i, i + 1)) >= 0) {
        count++;
    }
}
