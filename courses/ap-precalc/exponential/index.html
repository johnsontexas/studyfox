Unit 2A: Exponential functions and sequences

Open in StudyFox Free, no ads. Practice, track progress and quiz yourself in the app.

AP Precalculus · Lesson 5 of 9 · 8 min read

  • Arithmetic sequences add a constant: $a_n = a_0 + dn$. Geometric sequences multiply by a constant: $g_n = g_0r^n$.
  • Exponential functions $f(x) = ab^x$: over equal-length input intervals, outputs change by a constant ratio. Growth if $b > 1$; decay if $0 < b < 1$.
  • Percent change: growing 6% per year gives $b = 1.06$; decaying 6% gives $b = 0.94$.
  • Natural base: $e \approx 2.718$; continuous growth $A = Pe^{rt}$.
  • Composition and inverses: $f(g(x))$; an inverse swaps inputs and outputs.
Equal differences in outputs means linear. Equal ratios in outputs means exponential. Check a data table both ways.

Check your understanding

A table shows outputs 5, 15, 45, 135 for inputs 0, 1, 2, 3. Which model fits?

  1. Linear
  2. Quadratic
  3. Exponential with $b = 3$
  4. Exponential with $b = 10$
Show answer

Answer: C. Each output is 3 times the previous one, a constant ratio, so $f(x) = 5 \cdot 3^x$.
