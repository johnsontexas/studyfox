Linear equations and functions

Open in StudyFox Free, no ads. Practice, track progress and quiz yourself in the app.

SAT Math: Algebra and Advanced Math · Lesson 1 of 6 · 8 min read

A linear function has the form $f(x) = mx + b$. On the SAT you must read $m$ and $b$ as real quantities, not just numbers.

$m$ is the rate of change (how much $y$ changes when $x$ goes up by 1). $b$ is the starting value (the value of $y$ when $x = 0$).
Example

A plumber charges $C = 75h + 40$ dollars for $h$ hours of work. What does 40 represent?

When $h = 0$, $C = 40$, so 40 is a fixed fee charged before any hours are worked. The 75 is the charge per hour.

Solving one-variable equations

Distribute, combine like terms, and isolate $x$. Watch for these special cases:

  • If the $x$ terms cancel and you get a true statement like $5 = 5$, there are infinitely many solutions.
  • If you get a false statement like $5 = 7$, there is no solution.
Tip "No solution" questions with a constant like $k$: set the $x$ coefficients equal and make sure the constants are different.

Check your understanding

For what value of $k$ does $3(x + 2) = kx + 5$ have no solution?

  1. $k = 2$
  2. $k = 3$
  3. $k = 5$
  4. $k = 6$
Show answer

Answer: B. Left side: $3x + 6$. With $k = 3$, you get $3x + 6 = 3x + 5$, which is never true. So there is no solution.
