Desmos is also a statistics tool.

Quick statistics from a list

Type a list in square brackets, then call a function on it: mean([4,8,15,16,23]), median(...), stdev(...). This is much faster than adding by hand.

Regression from a table

  1. Add a table (the + button, then table) and enter the data as $x_1$ and $y_1$.
  2. Type y_1 ~ mx_1 + b for a line of best fit, or y_1 ~ ab^{x_1} for an exponential model. Use the tilde key ~.
  3. Desmos prints the values of $m$ and $b$ (or $a$ and $b$).
Tip Standard deviation on the SAT is almost always a comparison ("which set has the larger spread?"). You rarely need the number, but stdev settles close calls.

Check your understanding

You type mean([4, 8, 15, 16, 23]) into Desmos. What does it show?

  1. $13.2$
  2. $15$
  3. $66$
  4. $12.5$
Show answer

Answer: A. The sum is $66$, and $66 \div 5 = 13.2$. (The median would be $15$.)
