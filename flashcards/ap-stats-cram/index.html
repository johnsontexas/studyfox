AP · Statistics · 24 cards

Describe a distribution
Shape, center, spread, and outliers, in context (SOCS)
Resistant measure
Not strongly affected by outliers, e.g. median and IQR
z-score
How many standard deviations a value is from the mean
Correlation r
Strength and direction of a linear relationship, from −1 to 1
r²
Percent of variation in y explained by the linear model with x
Residual
Actual − predicted; a random residual plot means a linear model fits
Extrapolation
Predicting outside the range of the data; unreliable
Simple random sample
Every group of n individuals has the same chance of being chosen
Stratified random sample
Split into similar groups (strata), then randomly sample from each
Cluster sample
Split into groups that each look like the population, then sample whole groups
Voluntary response bias
People choose to respond; usually those with strong opinions
Experiment vs. observational study
Only an experiment imposes treatments, so only it can show cause and effect
Confounding variable
Related to both the explanatory and response variable, so their effects get mixed up
Blocking
Group similar subjects, then randomize treatments within each block
Independent events
P(A and B) = P(A)·P(B)
Binomial setting
Binary outcomes, Independent trials, Number fixed, Same probability (BINS)
Sampling distribution
The distribution of a statistic over all possible samples of the same size
Central Limit Theorem
For large n (≥ 30), the sampling distribution of x̄ is about normal
Conditions for inference
Random, 10% condition (independence), and Normal/Large Counts
Confidence level meaning
In repeated samples, about C% of intervals capture the true parameter
P-value
Probability of a result at least this extreme if the null hypothesis is true
Type I error
Rejecting a true null hypothesis; probability α
Type II error
Failing to reject a false null hypothesis
Power
Probability of correctly rejecting a false null; rises with larger n or α
