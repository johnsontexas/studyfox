Computing ideas and vocabulary for AP CSP.

AP · Computer Science · 16 cards

Algorithm
A step-by-step process to complete a task
Sequencing, selection, iteration
The three building blocks of every algorithm
Abstraction
Hiding details to manage complexity, e.g. procedures and lists
Binary
Base-2 number system using 0s and 1s
Bit / byte
A bit is one binary digit; a byte is 8 bits
Overflow error
A number is too large for the bits available to store it
Lossless compression
Shrinks data without losing information
Lossy compression
Shrinks data more by discarding some information
Linear search
Checks each item in order; works on unsorted lists
Binary search
Halves a sorted list each step; much faster than linear search
Undecidable problem
No algorithm can solve it for every input
Internet protocols
TCP/IP route data in packets; HTTP handles web pages
Fault tolerance
The network keeps working when parts fail, thanks to redundancy
Phishing
Tricking someone into revealing personal information
Public key encryption
Anyone can encrypt with the public key; only the private key decrypts
Digital divide
Unequal access to computing and the internet
